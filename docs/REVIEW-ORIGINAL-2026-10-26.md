# Tetris Battle 코드 리뷰와 원작 대조

리뷰 기준 설치본: `/Applications/Tetris Battle.app`, bundle 35. 이후 아이템 안내 탭 추가본은 bundle 36. 검토일: 2026-10-26.

## 검토 범위

`Game`, `ClassicBattle`, `BattleRotation`, `GameModes`, `MatchRules`, 줄 삭제/블록 생성/HOLD, `ClassicArena`/메뉴/사이드 슬롯, 오디오, 물리 키보드 브리지와 Go WebSocket 전송 경로를 검토했다. 기존 엔진과 참조 이미지/맵/라이선스를 유지하면서 수정했다. 모든 코드에 버그가 없다는 보증이나 외부 보안 감사 결과는 아니다.

## 최종 플레이 방식

- 기본 로비 START: 원작 Battle 2P 프리셋. 2분, 5 KO, 폭탄줄, 원작 배틀 음악. 기본 빈 보드이며 MAPS에서 직접 고른 지형은 유지한다.
- Battle 2P+: 시작 설정의 프리셋에서 선택. 2 KO에 종료한다.
- 스피드전: 같은 초록색 두 보드/금속 슬롯 UI. 단계, 배속, 다음 가속까지 남은 시간을 슬롯에 표시한다. 기본은 Facebook 배틀 규칙이며 자유 설정으로 전환할 수 있다.
- 아이템전 기본: 경기 전 방패/Final Rush/Twin Bomb을 플레이어별로 선택. 경기 중에는 자동 적용하며 공격은 줄 삭제와 콤보로 발생한다. 현재 앱에서는 부스트를 무료로 고를 수 있다.
- 아이템전 블록 수집: 이전에 요청한 커스텀 기능 유지. 아이템이 든 줄을 지우면 수집하고 보드 왼쪽 슬롯에서 수동 사용한다.
- 수동 아이템 키: 1P V/B/N 또는 1/2/3. 한 키보드 2P R/T/Y 또는 7/8/9. 등록한 키보드 두 개는 각자 V/B/N 또는 1/2/3. 온라인은 자신의 1/2/3을 방장이 검증해 적용한다.
- 자동 부스트에는 별도 수동 로켓 발사 기능을 붙이지 않았다. 수동 키 공격은 블록 수집 방식의 확장 규칙이다.
- KO/콤보/T-SPIN 알림은 요청대로 판 아래에 둔다. 영구 KO/지운 줄/보낸 줄 수치는 유지한다.

## 정확도와 한계

공개 자료는 사전 선택 부스트, 방패 최대 15줄, 마지막 30초 Final Rush 최대 15줄, Twin Bomb 두 폭탄을 설명한다. 원작의 정확한 난수 분포와 프레임 단위 타이밍은 공개되지 않아 검증하지 못했다. 현재 방패는 시드 기반 확률 검사와 15줄 예산, Final Rush는 공격할 때 1줄씩 최대 15줄을 더하는 재구현이다. 이를 원작 바이너리와 완전히 동일한 알고리즘이라고 단정하지 않는다.

스피드전의 15초 간격 가속과 블록 수집 아이템전은 사용자가 요청한 확장 모드다. 원작 문서의 별도 정식 모드로 확인되지 않았으며, 원작 화면/공격 규칙을 적용한 것으로 구분한다. Facebook 계정·공식 친구·결제·에너지·공식 랭크·상점 서버는 복원하지 않았다. 실제 로컬 기록과 현재 연결된 상대만 표시한다. 현 맵은 기존 제공/추가 맵 9종이며 원작 12종 전체의 정밀 복원은 아니다. 합성 효과음과 일부 점수/튜닝의 미세한 차이도 남을 수 있다.

온라인 게임은 개인용 방장 권한 모델이다. 서버는 참가자의 좌석/명령과 방장만의 상태 전송을 제한하지만, 방장 자체를 불신하는 공개 대회용 안티치트/계정 시스템은 아니다. 미국 친구와의 실제 인터넷 지연이나 물리 아이폰/두 키보드 동시 입력을 이번 검사로 대신하지 않는다.

## 검증 결과

- 전체 테스트: 52개 파일, 414개 테스트 통과.
- 실제 앱 대상 타입 검사 통과: `npm --prefix client-nuxt run typecheck`.
- Go 전송 테스트와 `-race` 통과. `cmd/macos`는 테스트 파일 없음.
- 원작 로비/프리셋/2 KO 종료/맵 선택, 협동/재도전/저장, 아이템 실제 KO, 사운드 파형/음소거, 키보드 재등록 회귀 검사 통과.
- 새 UI: 슬롯이 보드와 LINES SENT 숫자를 가리지 않음, 실제 CPU 공격의 회색 폭탄줄/방사능 표시, 스피드 단계 변경, 모바일 레이아웃/터치용 큰 아이템 버튼 확인.
- 수동 아이템 공격: 공유 키보드 1P Digit1/2P Digit7, 실제 WebSocket 호스트/게스트 Digit1의 상대 공격·자기 슬롯 소비·상태 동기화 확인.
- HID 명령/권한 수명주기 검사는 모의 OS 결과를 사용. 물리 키보드 숫자키의 실제 동시 입력은 별도 사람 플레이 검사가 필요하다.
- 네이티브 빌드/설치/엄격한 서명 확인 및 `/desktop-health` 통과. 중간 설치본의 QUIT로 앱/서버/포트가 함께 정리되는 것도 확인했다.
- 다운로드 ZIP과 소스 미러를 최종 bundle 35로 업데이트.
